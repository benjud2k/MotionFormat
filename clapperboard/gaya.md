# Lembar gaya — "Buat apa papan klak?"
- **Gaya:** Kartun Cel Cerah (`kartun-cel`), set A siang, **lokasi baru: set syuting outdoor** (langit, bukit, kota kecil, rumput bergaris, lampu softbox, kursi sutradara, boom mic).
- **Palet:** langit #2B9BF4→#7CC8FF→#D4F1FF · rumput #9BE36E/#6CCB5A/#3E9E4E · papan #2E2846 · tinta #2B1A3F · aksen koral #FF4F64 · kuning #FFD23F · biru #2EC5FF.
- **Tokoh:** BIMO, kru film (potongan cepak, kaos putih, rompi kru oranye #FF8A3D, sepatu merah), 6 kepala, wajah 3/4.
- **Font:** Dela Gothic One (judul, KLAK!, label nama) + Kanit 800 (balon, chip, tulisan kapur di papan).
- **Kamera:** dolly/crane lambat + paralaks 7 lapis, zoom kejut ke wajah tiap 10–15 dtk + garis fokus.
- **Cahaya/tekstur:** matahari kiri-atas, sinar diagonal, cahaya softbox (screen), vinyet ≤ .22, grain .04.
- **Subtitle:** balon kata putih bergaris tinta di AMAN.bawah, ekor ke mulut BIMO, kata aktif koral.
- **Tanda tangan gerak:** "KLAK!" — stik papan menutup cepat → teks KLAK! kuning + kilat putih + getar kamera.
- **Beda dari contoh:** lokasi luar ruangan, tokoh pria, onomatope KLAK! sebagai pemisah babak.
